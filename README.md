# 奶茶高考 · 院校数据库网站

面向河南考生的高考志愿参考网站。纯静态，无后端、无接口依赖。

## 快速开始

```bash
# 1. 从小程序数据构建网站数据产物
node scripts/build-data.js

# 2. 本地预览
cd site && python3 -m http.server 8899
# 打开 http://127.0.0.1:8899/index.html
```

## 页面

| 路径 | 说明 |
|---|---|
| `index.html` | 院校库：搜索 + 多维筛选 + 6 种排序 |
| `school.html?id=<id>` | 院校详情：层次、双一流学科、专业设置、冲稳保定位 |
| `majors.html` | 专业库：73 个本科专业方向 |
| `major.html?id=<id>` | 专业详情：课程、就业、深造、开设院校 |
| `score.html` | 河南 2025 一分一段表，支持分数查位次 |
| `about.html` | 数据来源、覆盖率与口径说明 |

## 数据来源

- **院校名单**：教育部《全国高等学校名单》（2025 年 6 月），951 所公办本科
- **985 / 211 / 双一流**：教育部公布名单，按校名匹配
- **河南一分一段**：河南省教育考试院公布分数段统计表
- **录取位次**：公开渠道整理的 2025 年录取最低分，由一分一段换算累计位次

## 重要口径提醒

1. **录取最低分 ≠ 投档线**。本站位次为「录取最低分」口径，志愿填报应以省考试院公布的投档线为准。
2. **冲稳保仅供定位参考**，无法反映专业组差异与招生计划变化。
3. **保研率口径各校不统一**，跨校比较需谨慎。
